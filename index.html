02

Gameplay & AI Programmer · Unity

Scam the AI ↗

Built a conversational AI NPC in Unity by integrating multiple OpenAI services into a single gameplay pipeline. Developed asynchronous speech-to-text, conversational AI, and text-to-speech interactions; engineered prompts and response triggers for gameplay states; and created a reusable desktop-style UI system with draggable windows and configurable microphone input. The project strengthened my experience integrating external APIs and turning AI services into interactive game systems.

  • Unity
  • C#
  • OpenAI Integration
  • Speech Recognition
03

Engine Programmer · C++

Holly Jolly Engine ↗

Built a lightweight C++ game engine and visual level editor with a component-based object system. Implemented editor selection and manipulation through ImGui, configurable gameplay components, collision behavior, and scene serialization for saving and loading levels. The project gave me hands-on experience building editor tools and workflows that allow developers to create game content without modifying engine code.

  • C++
  • Editor Tools
  • Component Architecture
  • Engine Systems
04

Gameplay Programmer · Unreal Engine 5

Liminal Detective ↗

Gameplay Programmer on a 10-person Unreal Engine team, working closely with combat designers to implement combat systems, enemy AI, player abilities, and supporting UI. Built behavior-driven enemies using Unreal’s AI systems, developed interconnected abilities including projectile marking, recall, grabbing, throwing, and stun interactions, and created systems that safely paused and resumed AI behavior during gameplay interactions. Iterated on combat architecture and balance through frequent playtesting and designer feedback.

  • Unreal Engine 5
  • Blueprints
  • Gameplay Systems
  • Combat AI
